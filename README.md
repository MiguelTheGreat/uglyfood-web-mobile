# UglyFood AI — Rescued Harvest Marketplace & AI Produce Grader

**Live GitHub Pages App:** [https://miguelthegreat.github.io/uglyfood-web-mobile/](https://miguelthegreat.github.io/uglyfood-web-mobile/)

An interactive, responsive Web & Mobile experience for **UglyFood AI**—connecting local smallholder farmers directly with households (**B2C**) and commercial kitchens (**B2B**) to buy and sell AI-verified safe, imperfect produce at **45%–52% below retail prices**.

## Design & Motion Highlights

- **Apple Liquid Glass Everywhere:** Curved `28px–32px` Liquid Glass cards, floating navigation & role-switcher capsules, concentric inset modal/cart sheets (`32px` outer / `12px` padding / `20px` inner), Clear Liquid Glass HUDs with `35%` media dimming, and a luminous organic ambient backdrop so every glass surface refracts warm color.
- **Warm Organic Palette (Inspired by Lumina):** Light warm parchment (`#f6f2e9`) and Gallery Noir dark mode (`#12110f`) paired with harvest bronze and emerald accents.
- **Typography:** `Fraunces` (warm, curved organic display serif) + `Plus Jakarta Sans` (clean, rounded modern UI with tabular numerals).
- **Apple HIG Spring Physics:** Smooth sliding Liquid Glass active-tab indicators across the top navigation, role switcher, and large thumb-friendly mobile bottom tab bar (`54px+` touch targets), plus transient Liquid Glass slider/toggle knobs and full accessibility support (`prefers-reduced-transparency`, `prefers-contrast`, `prefers-reduced-motion`).
